# HIV Cure Research Lab

In-silico исследовательская лаборатория ВИЧ в браузере: **симуляции на R (WebR)**,
**ИИ-копилот через LM Studio**, **P2P-обмен** и **мониторинг здоровья**. Данные
хранятся только в вашем браузере.

> ⚠️ **Важно / Disclaimer.** Это образовательный и исследовательский инструмент.
> Он **не изобретает лекарство** и **не является медицинским советом, диагнозом
> или лечением**. Результаты симуляций — упрощённые in-silico гипотезы, требующие
> лабораторной, доклинической и клинической проверки. По вопросам здоровья
> обращайтесь к врачу. / This is an educational research tool. It does **not**
> discover a cure and is **not medical advice**. Simulation outputs are simplified
> hypotheses. Consult a clinician.

## Что внутри / Features

- **Лаборатория (R / WebR).** Настоящий R в браузере (WebAssembly). Модели:
  - динамика ВИЧ (модель Перельсона, RK4): эффективность кандидата → траектории
    вирусной нагрузки и CD4, время до подавления (< 50 копий/мл);
  - доза–эффект (Hill / IC50);
  - фармакокинетика (однокамерная, многократные дозы);
  - связка ФК/ФД → вирусная нагрузка (режим дозирования → прогноз исхода).
- **ИИ-копилот (LM Studio).** Объясняет результаты, предлагает параметры и
  **генерирует R-код**, который тут же запускается (цикл «дизайн → проверка»).
- **P2P (WebRTC / PeerJS).** Обмен кандидатами, симуляциями и сообщениями напрямую
  между браузерами, без центрального сервера.
- **Мониторинг здоровья.** Вирусная нагрузка, CD4, приём АРВ-терапии и
  приверженность, визиты; трактовка порогов и U=U.
- **Раздел исследований.** Курируемые сводки со ссылками (актуально на май 2026).
- **Двуязычный интерфейс (RU/EN)**, светлая/тёмная тема, экспорт/импорт данных.

## Быстрый старт / Quick start

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # типы + продакшн-сборка в dist/
npm run preview  # предпросмотр собранного приложения
```

> При первом открытии раздела «Лаборатория» движок R (WebAssembly) скачивается с
> CDN WebR — нужен интернет. Дальше всё считается локально в браузере.

## Подключение ИИ (LM Studio) / AI setup

1. Установите [LM Studio](https://lmstudio.ai), загрузите модель и запустите
   локальный сервер (вкладка **Developer**).
2. В **Server Settings** включите **CORS**.
3. В приложении: **Настройки → Сервер ИИ**, URL по умолчанию
   `http://localhost:1234/v1`. Ключ не требуется.

> Надёжнее всего ИИ работает, когда приложение запущено локально (`npm run dev`),
> т.к. страница и LM Studio на одном `http://localhost`. На сайте по HTTPS
> (GitHub Pages) браузеры обычно разрешают запросы к `http://localhost`, но это
> зависит от браузера.

## P2P

Нажмите «Выйти в сеть» — появится короткий код. Передайте его собеседнику; он
вводит код и подключается. Публичный брокер PeerJS используется только для
установления соединения (сигналинга); данные идут напрямую между браузерами.

## Приватность / Privacy

Все ваши данные хранятся только в `localStorage` этого браузера. Ничего не
отправляется на сервер: ИИ обращается к вашему локальному LM Studio, P2P-данные
идут напрямую между пирами. Резервная копия — через **Настройки → Экспорт**.

## Деплой на GitHub Pages / Deploy

Workflow `.github/workflows/deploy.yml` собирает и публикует приложение. Один раз
включите в репозитории **Settings → Pages → Source: GitHub Actions**. (На приватных
репозиториях GitHub Pages требует платный план.) Собранная папка `dist/` —
статическая и работает на любом статическом хостинге.

## Технологии / Stack

React + TypeScript + Vite, Tailwind CSS, Recharts, [WebR](https://docs.r-wasm.org/webr/latest/),
PeerJS, OpenAI-совместимый API LM Studio.
